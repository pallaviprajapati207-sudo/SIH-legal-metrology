# Theme - Smart Legal Metrology Compliance Checker

## 1. Design Direction

Visual identity:

Professional
Government/Enterprise
Trustworthy
Modern
Technology-driven
Evidence-focused

The interface should feel like a serious inspection and compliance platform.

Avoid:

- Neon colors
- Gaming UI
- Excessive gradients
- Excessive animations
- Cartoonish illustrations
- Fake government seals
- Fake government logos
- Fake official certifications

# 25. Accessibility

Minimum requirements:

- Good color contrast
- Keyboard navigation
- Visible focus states
- Accessible labels
- Alt text
- Buttons must be understandable without icons
- Do not rely only on color to communicate PASS/FAIL

Example:

Green badge + "PASS"

not only green color.
